1. O que são Redes de Computadores

Rede de computadores é a conexão entre dois ou mais dispositivos (computadores, celulares, servidores) para compartilhar dados, internet e recursos.

2. Tipos de Redes
LAN (Local Area Network) 🏠
Rede local, pequena área (casa, escola, empresa).
MAN (Metropolitan Area Network) 🌆
Rede que cobre uma cidade.
WAN (Wide Area Network) 🌍
Rede de grande distância.
Exemplo: a Internet.
3. Topologias de Rede

Forma como os dispositivos se conectam:

Estrela ⭐ – todos ligados a um switch/roteador.
Barramento 🧵 – todos ligados no mesmo cabo.
Anel 🔄 – dispositivos conectados em círculo.
Malha 🕸️ – vários caminhos entre os dispositivos.
4. Dispositivos de Rede
Roteador 📶 – conecta redes diferentes e distribui internet.
Switch 🔀 – conecta dispositivos dentro da rede.
Modem 🌐 – faz a comunicação com o provedor de internet.
Access Point 📡 – cria rede Wi-Fi.
5. Protocolos de Rede

Protocolos são regras de comunicação entre computadores.

Principais:

TCP – garante entrega correta dos dados.
IP – identifica os dispositivos na rede.
HTTP – usado para acessar sites.
FTP – transferência de arquivos.
6. Endereço IP

É o identificador de cada dispositivo na rede.

Exemplo:
192.168.0.1

Pode ser:

IPv4 – formato numérico comum
IPv6 – versão mais nova com mais endereços
7. Modelo OSI

Modelo que divide a comunicação em 7 camadas:

Física
Enlace
Rede
Transporte
Sessão
Apresentação
Aplicação

Ele ajuda a organizar como os dados são enviados pela rede.

✅ Resumo geral:
Redes de computadores permitem que dispositivos se conectem para trocar dados. Elas utilizam equipamentos (roteador, switch), protocolos (TCP/IP) e estruturas organizadas (modelo OSI) para garantir comunicação eficiente.
